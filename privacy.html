Политика конфиденциальности «Мини-бар бот»

Дата обновления: 20 ноября 2026 г.

Что это за приложение

«Мини-бар бот» — внутренний инструмент гостиницы для учёта продаж товаров мини-бара и ресепшна. Им пользуются только сотрудники гостиницы через Telegram.

Какие данные обрабатываются

  • Telegram ID и имя сотрудника — чтобы определить его права в боте.
  • Записи об операциях: дата, товар, количество, цена, номер комнаты, имя сотрудника.
  • Фотографии чеков закупки, которые отправляет владелец, — для распознавания товаров и цен.

Бот не собирает данные гостей, кроме номера комнаты в записи о продаже.

Где хранятся данные

Данные хранятся в Google Таблице, принадлежащей гостинице. Доступ к ней есть только у владельца.

Доступ к Google-аккаунту

Приложение запрашивает доступ только к одной Google Таблице, в которой оно установлено, и разрешение отправлять запросы к Telegram и к сервису распознавания чеков. Другие файлы, почта и данные Google-аккаунта не используются.

Передача третьим лицам

Сообщения проходят через Telegram. Фотографии чеков передаются в Claude API (Anthropic) только для распознавания. Данные не продаются и не передаются для рекламы.

Удаление данных

Чтобы удалить свои данные или прекратить доступ к боту, сотрудник может обратиться к администрации гостиницы.
